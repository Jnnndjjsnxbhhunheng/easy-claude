# Code Review 技能

## 审查维度

### 1. 正确性
- 逻辑错误、边界条件
- 空指针/未定义引用
- 错误处理是否完善

### 2. 安全性
- SQL 注入、XSS、命令注入
- 敏感数据暴露
- 认证/授权缺陷

### 3. 性能
- 不必要的循环或重复计算
- 内存泄漏风险
- N+1 查询问题

### 4. 可维护性
- 命名是否清晰
- 函数是否过长（建议 < 50 行）
- 是否有重复代码（DRY 原则）

### 5. 最佳实践
- 遵循语言惯例
- 类型注解（Python/TypeScript）
- 测试覆盖

## 输出格式

```
## 代码审查报告

### 严重问题 🔴
- [问题描述] (行号)

### 警告 🟡
- [问题描述] (行号)

### 建议 🟢
- [改进建议]

### 总结
[整体评价]
```
