# Web Assistant 技能

## 功能

### 内容提取
- 提取文章主要观点
- 识别关键数据和统计信息
- 总结长文档

### 信息分析
- 对比多个来源的信息
- 识别事实与观点
- 时间线整理

### 格式化输出
- Markdown 格式的摘要
- 结构化数据提取（表格/列表）
- 多语言翻译支持

## 使用方式

当用户需要分析网页或文本内容时：
1. 使用 `search_files` 工具查找本地文件
2. 使用 `bash` 工具执行 curl 获取网页内容
3. 按照上述维度进行分析

## 输出模板

```
## 内容摘要

**来源**: [URL/文件名]
**主题**: [核心主题]

### 关键信息
- [要点1]
- [要点2]

### 详细分析
[分析内容]
```
